Autorunner Guide
================

The **pyxalign-autorunner** is a step-by-step GUI workflow for loading,
aligning, and reconstructing laminography or tomography datasets. It
guides you through each stage of the pipeline interactively, allowing
you to inspect and adjust settings at every step.
